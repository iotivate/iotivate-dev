We're excited to launch **iotivate.dev** — a platform dedicated to making IoT development simpler and more accessible.

## What we're building

Our focus is on practical, browser-based tools that eliminate the friction of getting started with ESP32 and IoT projects:

- **Web-based firmware flasher** — No drivers, no desktop apps. Just connect your board and flash.
- **Project showcases** — Real builds with source code, schematics, and documentation.
- **Firmware resources** — Ready-to-use firmware for common use cases.

## Why we built this

Too many IoT projects die in setup hell. Installing toolchains, configuring drivers, debugging connection issues — all before you even get to the interesting part.

We're building tools that skip the ceremony and let you focus on what matters: building things.

## What's next

We're actively working on:

1. ESP32 Web Flasher with Web Serial API support
2. WirelessEar project documentation
3. More tools and installers

Stay tuned for updates, and let us know what tools you'd find useful.
